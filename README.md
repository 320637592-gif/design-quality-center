# 设计质量中心

工作台网址：https://320637592-gif.github.io/design-quality-center/

本仓库保存已构建的网页发布文件，由 GitHub Pages 发布。

## Figma 规范解析

在“设计规范”中添加有读取权限的 Figma 设计文件链接。页面通过当前电脑运行的工作台读取真实内容，默认读取 Figma 当前内容；较多文件会排队，暂时失败的批次会缩小后重试。

读取时需保持本机工作台运行。网页会在当前页面直接连接工作台，不再弹出本机确认窗口；连接失败时会留在当前页面提示重新启动工作台。Figma 授权信息保留在本机。结果包含读取日期和覆盖范围，未读完或未支持的内容会明确标注，不会自动应用到走查。

GitHub Pages 托管网页，不运行本机的 Figma 读取、自动截图和自动走查服务。浏览器演示账号也仅保存在当前浏览器。

## 发布方式

发布目录保留完整原始图标资源和 `.nojekyll`，资源路径已适配本项目子目录。更新 `main` 分支后，GitHub Pages 从仓库根目录发布。

源代码及本机服务保留在原工作项目；本仓库不包含本地解析记录、授权信息和原始 Figma 文件。
