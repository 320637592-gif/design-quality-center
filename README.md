## Figma 规范解析

在“设计规范”中可直接上传从 Figma 导出的 `.fig` 文件，也可粘贴有读取权限的 Figma 设计文件链接。推荐上传 `.fig` 文件：当前电脑运行的工作台会离线读取真实节点和属性，原文件不会上传到公开网站。

读取时需保持本机工作台运行。网页会在当前页面直接连接工作台，不再弹出本机确认窗口；连接失败时会留在当前页面提示重新启动工作台。链接读取需要编辑权限或本机配置的只读凭证，只有查看权限时请改用 `.fig` 文件。

结果按字体、图标、颜色、间距、圆角和组件六类展示。达到读取上限、属性混合或格式暂不支持时会明确标为部分内容，不会补入示例数据，也不会自动应用到走查。若本机配置了 DeepSeek，模型只抽样核对分类；精确数值始终取自文件原始属性，密钥不会进入网页或仓库。

GitHub Pages 托管网页，不运行本机的 Figma 读取、自动截图和自动走查服务。浏览器演示账号也仅保存在当前浏览器。

## 发布方式

发布目录保留完整原始图标资源和 `.nojekyll`，资源路径已适配本项目子目录。更新 `main` 分支后，GitHub Pages 从仓库根目录发布。

源代码及本机服务保留在原工作项目；本仓库不包含本地解析记录、授权信息和原始 Figma 文件。
